# Maquette du front de WaveLocalAI v2

Maquette HTML interactive du front définitif (données simulées, aucun serveur applicatif). Double-cliquez sur `ouvrir.cmd` (Windows) ou lancez `python serveur.py` dans ce dossier. Le bouton « Scénarios (maquette) », en bas à droite, force des états et rejoue des flux.

Pour les agents qui construisent les écrans : `CONVENTIONS.md`. Écarts et questions : `notes/`.
