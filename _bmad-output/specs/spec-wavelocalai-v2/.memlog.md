- (decision) §6 n°2 révisé (Anaël, remplace l'entrée pydantic-ai) : boucle d'outils et équipe séquentielle maison sur un port ChatModel aux 4 adaptateurs (Ollama natif /api/chat, OpenAI/Groq, Anthropic, Mistral), reprise du harnais ; ni LangChain, ni LangGraph, ni CrewAI, ni pydantic-ai. Raison : D3 exige l'API native d'Ollama, trace pédagogique fidèle, pas de dépendance à cadence rapide.
- (decision) La question ouverte sur pydantic-ai est close par la décision n°2 révisée.
- (decision) §6 n°4 (Anaël) : évaluation RAG par un juge maison à sortie structurée (format d'Ollama, tool_use Anthropic, schéma OpenAI) ; fidélité = affirmations extraites puis vérifiées une à une contre le contexte, verdict par affirmation affiché ; pertinence = questions générées depuis la réponse, cosinus avec la question ; noms fidélité/pertinence gardés, méthode Ragas citée ; échec du juge = « non mesurable », jamais 0 ; calibré sur un jeu fixe de cas de non-régression ; Ragas retiré.
- (decision) §6 n°5 (Anaël) : CO₂ local mesuré par run avec CodeCarbon hors du fil de requête, marqué « estimation » sans RAPL ; cloud par ecologits quand il connaît le modèle, marqué « estimation » avec fourchette ; sinon « non mesurable » avec sa raison, jamais 0 ni « — » ; une estimation qui échoue n'arrête jamais l'appel ; CO₂ de session = somme des réponses mesurées ; plus de tracker par session ni de constante par token.
- (question) ecologits couvre-t-il Groq et les modèles Mistral actuels ? À vérifier avant la story Carbone.
