### Banc d'essai (story 7.4)

Noms de champs fixés par la story serveur 7.4 (décision du 2026-10-19, écart n° 18). Le serveur calcule le verdict de format et toutes les mesures (AD-20).

- **Scénarios** : `GET /api/scenarios` rend `{scenarios: [{id, name, instruction, input, schema}]}` : les six scénarios de la v1 (`USE_CASES`), `id` stable (`classification`, `traduction`, `extraction`, `code`, `raisonnement`, `resume`), `instruction` = la consigne système (D-18, séparée de l'entrée), `input` = l'exemple d'entrée, `schema` = le format attendu en schéma JSON d'un objet (`type`, `properties`, `required`, `additionalProperties: false`, `enum`), ou `null` pour un scénario sans format (D-17). La consigne de l'extraction nomme ses trois champs (`date`, `montant`, `vendeur`), ce que la v1 ne faisait pas.
- **Commande** : `POST /api/bench/runs {scenario, model, input, force_format, concise, allow_cloud}` rend `{run_id}` ; `input` : 1 à 20 000 caractères non blancs ; `force_format` sur un scénario sans format, un scénario inconnu ou une entrée vide : `422 invalid_request` ; modèle inconnu, cloud non autorisé, modèle qui n'est pas de conversation : `model_not_found`, `cloud_not_allowed`, `model_not_chat` ; un banc déjà actif : `409 run_busy` (`detail.run_id`). `force_format` passe le schéma par `response_schema` (`format` d'Ollama, AD-8) ; `concise` ajoute à la consigne « Réponse concise : va droit au but, sans introduction ni commentaire superflu. » ; température fixe de 0,2 (celle de la v1).
- **Run** : racine `bench` (`params` : `scenario`, `force_format`, `concise`, `allow_cloud`, jamais de texte saisi, AD-7), une génération, racine et feuille à la fois comme le chat, sans conversation. Un run, `run_busy` au deuxième.
- **Événements** : le flux est celui d'une génération (`run_started`, `model_loading`, `model_loaded`, `token`, `retry`, `metrics`, `run_ended`) plus `bench_input` : `{scenario, text}`, publié juste après `run_started` (l'entrée saisie vit dans le flux). Pour un scénario avec format, `metrics` porte aussi `format_verdict`.
- **`format_verdict`** : `{ok, message, formatted, forced}` ; `message` est « Format respecté » ou la **première** violation en clair (« « sentiment » : valeur hors de la liste permise (Positif, Neutre, Négatif) », « « de » : champ requis absent », « La sortie n'est pas du JSON valide (ligne 1, colonne 8) », « La sortie a du texte après son JSON (ligne 1, colonne 35) », « La sortie a du texte autour de son bloc JSON », « La sortie est vide » ; `NaN` et `Infinity` ne sont pas du JSON) ; `formatted` est le JSON mis en forme (indent 2), lu même quand il viole le schéma, `null` s'il n'est pas lisible ; `forced` reprend `force_format`. Une clôture Markdown autour du JSON est tolérée (comme par les adaptateurs). Un format imposé que l'adaptateur juge violé (`invalid_output`) ne finit pas en erreur : le Banc termine le flux, le run est `ok`, sans compte de jetons ni débit, et le verdict dit la violation. Absent d'un scénario sans format, d'un run annulé ou en erreur (délai compris).
- **Instantané** `GET /api/runs/{id}` (kind `bench`) : en plus des champs communs (`metrics` : débit D3, CO₂, durée, chargement), `bench` `{scenario, force_format, concise, input, output}` (la sortie est le texte de réponse du flux, partiel compris) et, quand il existe, `format_verdict` au niveau de l'instantané. C'est ce que lit `#/arene/banc/<run_id>` : aucun modèle relancé ; identifiant inconnu : `404 run_not_found`.
- **Liste** : `GET /api/bench/runs?limit=` (1 à 100, 20 par défaut) rend `{runs: [{run_id, status, started_at, ended_at, scenario, model, force_format, concise, format_ok, input}]}`, les plus récents d'abord ; `format_ok` : `true`, `false` ou `null` sans verdict ; `input` : les 200 premiers caractères. Pas d'effacement d'un banc dans cette story.
- **`structured_output`** : booléen de `GET /api/models`, vrai pour tout modèle de conversation (local par `format` d'Ollama, cloud par le schéma de son fournisseur), faux pour un embedder ou un reranker ; le front désactive « Format imposé » avec la raison quand il est faux.
